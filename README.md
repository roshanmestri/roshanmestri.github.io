# roshanmestri.github.io

My portfolio. Next.js (static export) + Tailwind, deployed to GitHub Pages by GitHub Actions on every push to `main`.

- All text lives in `src/content/site.ts`.
- Replace `public/resume.pdf` to update the resume.
- `npm run dev` to preview at http://localhost:3000, `npm run build` to export to `out/`.
